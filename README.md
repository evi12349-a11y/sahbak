# 🤖 סחבק — עוזר אישי ל-WhatsApp

בוט וואטסאפ אישי בעברית לניהול **יומן גוגל**, **משימות** (מטריצת אייזנהאואר) ו**תקציב חודשי** — מבוסס **Google Gemini** עם הבנת שפה טבעית.

תומך בטקסט, **הקלטות קוליות** 🎤, **תמונות** 📷 ו-**PDF** 📄.

## ✨ מה חדש בגרסה הזו (התיקונים)

הגרסה הזו פותרת את הבעיות שגרמו לבוט להיות איטי, לקרוס ו"לא להבין":

| # | מה תוקן | איך |
|---|---------|-----|
| 1 | **קריסות ועומס מ-Webhooks** | השרת מחזיר ל-WhatsApp `200 OK` תוך מילישניות ומעבד את התשובה ברקע על **thread pool** מוגבל. כך אין יותר timeouts ושליחות כפולות. |
| 2 | **"שגיאה זמנית בשרתי AI"** | כל קריאה ל-Gemini עטופה ב-**Exponential Backoff** עם jitter (1s → 2s → 4s). שגיאות זמניות (עומס / rate-limit / 5xx) נוסות שוב אוטומטית; שגיאות קבועות נכשלות מיד. |
| 3 | **הבוט "לא מבין"** | מעבר ל-**Function Calling** אמיתי — Gemini מחזיר פעולות מובְנות ומאומתות במקום טקסט חופשי לפענוח. כמעט אפס קריסות הבנה. תומך גם ב**כמה פעולות בהודעה אחת**. |
| 4 | **הודעות קוליות נופלות** | תמלול עובר דרך אותו צינור אסינכרוני + retry, ואז מנותב כאילו הוקלד (יוצר אירועים/משימות/הוצאות). |

### שיפורים נוספים שנכנסו
- 🗑️ **מחיקת משימות** ("מחק את המשימה של החלב"), בנוסף לסימון כהושלם.
- 🕐 **תיקון אזור זמן** ביצירת אירועים + התרעה אם הזמן שביקשת כבר עבר.
- ✂️ **פיצול הודעות ארוכות** למספר הודעות (במקום חיתוך באמצע מילה ב-4096 תווים).
- 🔁 **Retry גם על שליחת WhatsApp והורדת מדיה**, לא רק על ה-AI.
- 🧹 **ניקוי אוטומטי** של טבלת ה-dedup (לא גדלה לאינסוף).
- ✅ **ולידציות**: סכום הוצאה חיובי, קטגוריות חוקיות, ברירת מחדל חכמה לרביע משימה.
- ⚡ פקודות מיידיות ("תפריט") רצות בלי קריאת AI — חוסך זמן ועלות.

## 🚀 התקנה ב-Railway (צעד אחר צעד)

### 1. העלאת הקוד ל-GitHub
העלה את כל הקבצים (`app.py`, `requirements.txt`, `Procfile`, `runtime.txt`, `.gitignore`) ל-repository חדש ב-GitHub.

### 2. יצירת פרויקט ב-Railway
1. ב-[Railway](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
2. בחר את ה-repo. Railway יזהה Python ויתקין הכל מ-`requirements.txt`.

### 3. הגדרת משתני סביבה (Variables)
ב-Railway, בלשונית **Variables**, הוסף:

| משתנה | חובה? | תיאור |
|-------|-------|-------|
| `WHATSAPP_TOKEN` | ✅ | טוקן ה-WhatsApp Cloud API (מ-Meta for Developers). |
| `PHONE_NUMBER_ID` | ✅ | ה-Phone Number ID שלך מ-Meta. |
| `GEMINI_API_KEY` | ✅ | מפתח Gemini מ-[Google AI Studio](https://aistudio.google.com/apikey). |
| `VERIFY_TOKEN` | ✅ | סוד אקראי וחזק לאימות ה-Webhook של Meta. אין להשתמש בו באוטומציות תשלום. |
| `APP_SECRET` | ✅ | ה-App Secret מ-Meta. חתימת כל Webhook נכנסת נבדקת; בלי הערך, בקשות Webhook נדחות. |
| `ALLOWED_USERS` | נדרש להפעלה | מספרים מאושרים בפורמט WhatsApp, מופרדים בפסיקים. יש להוסיף לפחות את מספר המנהל הראשון; משתמשים נוספים יכולים להתווסף דרך אישור מנהל. בלי משתמשים מאושרים, הודעות נכנסות נדחות. |
| `GOOGLE_CREDENTIALS` | ליומן | תוכן ה-JSON המלא של חשבון שירות (Service Account) של Google Cloud. הדבק את כל ה-JSON כערך אחד. |
| `CALENDAR_ID` | ליומן | מזהה היומן (ברירת מחדל `primary`). אם משתמשים ב-Service Account, צור יומן ושתף אותו עם כתובת המייל של החשבון, ושים כאן את ה-ID שלו. |
| `TIMEZONE` | לא | ברירת מחדל `Asia/Jerusalem`. |
| `GEMINI_MODEL` | לא | ברירת מחדל `gemini-2.5-flash`. |
| `WHATSAPP_API_VERSION` | לא | ברירת מחדל `v21.0`. |
| `DB_PATH` | לא | נתיב למסד הנתונים. **לשמירת מידע בין פריסות — חבר Volume ב-Railway והצבע לכאן** (למשל `/app/data/sahbak.db`). |
| `MAX_WORKERS` | לא | מספר הודעות שמעובדות במקביל (ברירת מחדל `8`). |
| `SHABBAT_NOTIFICATIONS` | לא | התראות שבת וחגים אוטומטיות לפי Hebcal; כבויות כברירת מחדל (`false`). אין להפעיל עד שמוגדרות תבנית WhatsApp מאושרת ובדיקת הסכמה מפורשת למקבלים. |
| `SHABBAT_TEMPLATE_NAME` | נדרש להפעלה בטוחה | שם תבנית הודעת WhatsApp שאושרה ב-Meta. בלעדיה מתזמן ההתראות לא מתחיל ולא נשלחת הודעה. |
| `SHABBAT_NOTIFICATION_HOUR` | לא | שעת שליחת ההתראה לפי `TIMEZONE` (ברירת מחדל `12`). |
| `PAYMENT_TEMPLATE_NAME` | לא | תבנית Utility מאושרת עם משתנה גוף אחד עבור עדכוני Apple Pay/Android. בלי תבנית והסכמה מפורשת מהנמען, ההוצאה תירשם אך לא תישלח הודעת WhatsApp יזומה. |
| `PAYMENT_TEMPLATE_LANGUAGE` | לא | שפת תבנית עדכוני התשלום; ברירת מחדל `he`. |

אוטומציות תשלום מקבלות קוד חיבור אישי לכל משתמש מתוך לוח הבקרה. השרת שומר רק גיבוב של הקוד, וניתן להחליפו או לבטלו במסך החיבור. אוטומציות קיימות שמשתמשות ב-`VERIFY_TOKEN` צריכות להתחבר מחדש עם קוד אישי; אין להטמיע את `VERIFY_TOKEN` בקיצור או באפליקציית אוטומציה.

> ⚠️ **שמירת נתונים:** SQLite נשמר על דיסק. בלי **Volume** ב-Railway, המידע (הוצאות/משימות) יימחק בכל פריסה מחדש. כדי לשמור: צור Volume, חבר אותו (למשל ל-`/app/data`), והגדר `DB_PATH=/app/data/sahbak.db`.

### 4. חיבור ה-Webhook ב-Meta
1. ב-Railway, העתק את כתובת ה-domain הציבורי של השירות (למשל `https://your-app.up.railway.app`).
2. ב-Meta for Developers → WhatsApp → Configuration → **Webhook**:
   - **Callback URL:** `https://your-app.up.railway.app/webhook`
   - **Verify Token:** הערך שהגדרת ב-`VERIFY_TOKEN`.
3. הירשם (Subscribe) לשדה **messages**.
4. כדי לקבל גם אירועי מדיניות/השבתה מ-Meta, הירשם לאובייקט **WhatsApp Business Account** ולשדה **account_update**. השרת רושם את סוג האירוע ומידע ההפרה המצומצם ללוגים; ההרשמה עצמה חייבת להתבצע בלוח Meta.
5. הגדר את `APP_SECRET` של אפליקציית Meta. השרת דוחה Webhooks ללא חתימה תקינה.

### 5. בדיקה
- היכנס ל-`https://your-app.up.railway.app/health` — אמור להחזיר JSON עם `"status": "ok"` ולציין אילו שירותים מחוברים.
- שלח הודעה לבוט בוואטסאפ: `"היי"` → אמור לקבל הודעת ברוכים הבאים.

### שימוש דרך לוח הבקרה
כל הלקוחות יכולים להיכנס דרך כתובת אחת: `https://your-app.up.railway.app/dashboard`.
מנהל שמחובר ללוח האישי שלו יכול ללחוץ על כפתור ניהול הלקוחות, להזין מספר טלפון
ולהפיק קישור הפעלה חד־פעמי. יש להעביר את הקישור ללקוח באופן פרטי; תוקפו שבעה ימים.
הלקוח בוחר סיסמה אישית באורך 12 תווים לפחות, ולאחר מכן נכנס דרך הכתובת האחידה עם
מספר הטלפון והסיסמה. קישור הפעלה חדש למספר קיים מאפשר איפוס סיסמה לאחר שהלקוח
מפעיל אותו. הכניסה נשמרת בדפדפן עד 14 ימים, וניתן לצאת באמצעות כפתור היציאה.

הקישורים האישיים שנוצרו בעבר בפקודה `קישור` ממשיכים לעבוד, כך שאין צורך לנתק
לקוחות שכבר משתמשים בהם. אין להשתמש בסיסמה משותפת או בארבע הספרות האחרונות של
מספר הטלפון כסיסמה — הן אינן סוד ועלולות לחשוף לוח של לקוח אחר.

הלוח כולל סיכום תקציב,
תנועות ומשימות; בשלב זה שיחת הטקסט מהלוח זמינה למנהלים בלבד, ופקודות ניהול
ייעודיות ל-WhatsApp אינן זמינות בשיחה זו. השיחה משתמשת באותה לוגיקת עיבוד כמו
הבוט, אך הודעות ותזכורות היוצאות דרך WhatsApp עדיין דורשות חשבון WhatsApp פעיל
ולא יימסרו כשהחשבון מושבת. אין להשתמש במספר או בחשבון חדש כדי לעקוף החלטת אכיפה
של Meta. אפשר לצרף לשיחה תמונת אירוע (JPEG, PNG, WebP או HEIC, עד 5 MB); התמונה
נשלחת ל-Google Gemini לפענוח, סחבק ינסה לחלץ ממנה פרטים, יציג הצעה לאישור, ורק
לאחר אישורך ינסה ליצור את האירוע ביומן.
מנהלים יכולים לחבר את היומן שלהם מתוך השיחה בפקודה `חבר יומן you@gmail.com`;
תחילה יש לשתף את היומן עם חשבון השירות שמוצג בצ׳אט בהרשאת עריכה. דרך האתר ניתן
לחבר רק את היומן של המשתמש המחובר, ולא יומנים של משתמשים אחרים.
אם יצירת האירוע נכשלת, יש לבדוק שהיומן האישי מחובר ושחשבון השירות קיבל הרשאת
עריכה. במקרה של שגיאת תקשורת בדפדפן, בדוק קודם אם האירוע כבר נוצר לפני שליחה חוזרת.

הפעלת ה-Cloud API הרשמי אינה כשלעצמה אישור לשימוש בכל סוג מוצר. [תנאי Meta
ל-WhatsApp Business Platform](https://www.whatsapp.com/legal/business-solution-terms/)
מגבילים שימוש של ספקי AI כאשר עוזר AI כללי הוא הפונקציונליות העיקרית. מאחר
שסחבק מתואר כעוזר אישי מבוסס Gemini, יש לקבל ממטא אישור מפורש לזכאות השימוש
לפני רישום מחדש או חיבור מספר אחר. [הדיווח המצטט את נוסח התנאי ואת הבהרת Meta](https://techcrunch.com/2025/10/18/whatssapp-changes-its-terms-to-bar-general-purpose-chatbots-from-its-platform/).

### אירועים מפורשים ביומן

כאשר המשתמש מבקש להוסיף אירוע מסוים ומציין יום או תאריך ושעה, הבוט אמור ליצור
אותו בזמן שביקש. מגבלות שבת ושעות העבודה חלות על תכנון יזום של משימות ולימודים,
ולא על אירוע שהמשתמש ביקש במפורש.

### התראות שבת וחגים

ההתראות כבויות כברירת מחדל. הודעות יזומות מחוץ לחלון השירות של 24 שעות
מחייבות תבנית שאושרה ב-Meta, ויש לשלוח אותן רק לנמען שנתן הסכמה מפורשת בעצמו.
אישור מנהל לגישה לבוט אינו הסכמה לקבלת הודעות יזומות. המשתמש יכול לשלוח
`חזור` כדי להצטרף או `הפסק` כדי להפסיק.

לאחר אישור התבנית ובדיקת הסכמת כל הנמענים, כאשר `SHABBAT_NOTIFICATIONS=true`,
השירות שולף מדי יום את זמני הדלקת הנרות
וההבדלה מ-Hebcal ומחשב בנפרד את ירושלים ואת תל אביב. ההתראה נשלחת למשתמשים
המוכרים לבוט סביב השעה `SHABBAT_NOTIFICATION_HOUR` לפי אזור הזמן של `TIMEZONE`.
הודעות שכבר נשלחו נשמרות במסד הנתונים כדי למנוע כפילויות בין workers של Gunicorn.
המקור: [Hebcal Shabbat Times API](https://www.hebcal.com/home/197/shabbat-times-rest-api).

גם עדכוני תשלום מהתראות חיצוניות נשלחים רק באמצעות תבנית Utility מאושרת
והסכמה מפורשת של הנמען. קישור יומן למספר אחר אינו נשלח אוטומטית; המנהל מקבל
את פרטי השיתוף ויכול להעבירם רק למשתמש שביקש להצטרף. הודעות טקסט וכפתורים
חופשיים נשלחים רק בחלון השירות שפתח המשתמש בהודעה נכנסת, שאורכו 24 שעות.

## 🏗️ ארכיטקטורה בקצרה

```
WhatsApp  →  POST /webhook  →  ACK 200 מיד  ─┐
                                             │ (thread pool, ברקע)
                                             ▼
                          get_ai_tool_calls()  ── Gemini Function Calling (+retry)
                                             │
                          execute_tool()  ──→ יומן / משימות / תקציב (SQLite)
                                             │
                          send_whatsapp_message()  ── שליחת התשובה (+retry, פיצול)
```
